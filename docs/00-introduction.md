# 소개

## IrisGUI 란?

IrisGUI는 안드로이드 기기 한 대를 카카오톡 봇 서버로 만들어 주는 앱입니다.
기존에 따로 존재하던 두 프로젝트를 하나의 APK로 합친 것입니다.

- **Iris** — 루팅된 기기에서 동작. 카카오톡 데이터베이스를 직접 읽어 새 메시지를
  감지하고, 전체 기능의 API 서버를 제공합니다.
- **IrisLite** — 무루팅 기기에서 동작. 카카오톡 알림을 읽어 이벤트를 감지하고,
  답장은 알림 reply 기능으로 전송합니다.

과거에는 이 둘을 각각 PC에 연결해 따로 굴려야 했지만, IrisGUI는 설정 화면에서
모드만 고르면 같은 인터페이스로 둘을 오갈 수 있습니다.

## 무엇을 할 수 있나

- **실시간 메시지 수신** — 방·보낸이·본문을 포함한 이벤트를 WebSocket으로 실시간 스트리밍
- **메시지 발송** — 텍스트는 물론 사진(여러 장), 영상, 오디오, 파일 첨부 전송
- **기록 조회** — 채팅방 목록, 메시지 페이지네이션, 전문 검색, 리액션, 삭제된 메시지 회수
- **bot 개발** — Python 공식 클라이언트(irispy-client)로 어디서나 봇 작성, 기기 안에서 직접 실행도 가능
- **여러 기기 연동** — 하나의 이벤트를 여러 봇·여러 서버로 동시에 전달

## 실행 모드

앱은 기기의 환경을 확인해 세 가지 중 하나로 동작합니다. 상태 탭에서 직접 바꿀 수도 있습니다.

| 모드 | 대상 환경 | 이벤트 감지 | 사용 가능 기능 |
|---|---|---|---|
| **ROOT_ADB** | 루팅 기기, redroid 같은 에뮬레이터 | DB 직접 읽기 | 전부 (이벤트·답장·조회·검색) |
| **HAYUL** | HayulGUI 패치 적용 기기 | DB 직접 읽기 (권한 공유) | 전부 |
| **NON_ROOT** | 일반 스마트폰 | 알림 읽기 | 이벤트 수신과 텍스트 답장만 |

일반적인 실사용자는 ROOT_ADB 또는 NON_ROOT를 택합니다. NON_ROOT는 기기 설정에서
"알림 접근"만 허용하면 되므로 준비가 가장 간단하지만, 읽을 수 있는 정보가 알림에
표시된 내용 정도라서 기능에 제한이 있습니다. ROOT_ADB는 모든 기능을 쓸 수 있는 대신
루트 환경이 필요합니다.

## 용어 정리

여러 문서에서 반복되는 개념이라 미리 익혀 두면 좋습니다.

| 용어 | 의미 |
|---|---|
| **이벤트** | 새 메시지를 감지해 IrisGUI가 외부로 알리는 JSON 한 건 |
| **답장 / reply** | `POST /reply` 요청으로 IrisGUI가 카카오톡에 보내게 하는 메시지 |
| **webEndpoint** | 새 이벤트마다 IrisGUI가 JSON을 POST로 던져 주는 외부 서버 URL |
| **서버 포트** | IrisGUI API가 요청을 받는 네트워크 포트 (기본값 3000) |
| **bot id** | 내 계정의 카카오톡 사용자 ID. 감지된 메시지가 내 발신인지 구분할 때 사용 |
