## 한눈에 보는 작동 원리

IrisGUI는 카카오톡에서 새로 온 메시지를 잡아 두 개의 통로로 내보냅니다.

```
                        카카오톡 새 메시지
                               │
              ┌────────────────┴────────────────┐
              │ 루팅 환경: DB를 직접 읽어서 감지    │ 논루팅 환경: 알림을 읽어서 감지
              └────────────────┬────────────────┘
                               ▼
                     IrisGUI가 이벤트를 수집
                               │
        ┌──────────────────────┼──────────────────────┐
        ▼                      ▼                      ▼
  WebSocket /ws         HTTP POST(webEndpoint)   앱 내 스크립트 실행
  (실시간 스트리밍)      (원하는 서버로 전달)       (같은 /ws 접속)
        │
        ▼
   봇이 이벤트 수신 → 판단 → POST /reply 로 답장 발송
```

즉 세 가지만 기억하면 됩니다.

1. **이벤트를 받는다** — WebSocket `/ws` 또는 설정한 서버로 던지는 HTTP POST.
2. **판단한다** — 내 코드(컴퓨터의 irispy-client, 기기 안의 Python 등)가 내용을 보고 결정.
3. **보낸다** — `POST /reply` 로 텍스트·사진·영상·파일을 카카오톡에 전달.
